# بوسراج للألعاب — الإصدار الاحترافي 2.0

منصة ألعاب عربية تعمل على Cloudflare Workers، وتحافظ على «تحدي العباقرة» المحلي والأونلاين، وتضيف نسخًا Premium محلية وأونلاين من السلم والثعبان وجاكارو داخل نفس المشروع.

## الألعاب

### تحدي العباقرة — محلي
- 23 فئة و207 أسئلة من النسخة الأصلية.
- نظام نقاط ومساعدات وزوم وأسئلة صوتية/صورية.
- نظام صوت موحّد للمؤقت والجولات والإجابات.
- تصعيد صوتي في آخر 10 ثوانٍ، وتنبيه أقوى في آخر 5 ثوانٍ.

### تحدي العباقرة — أونلاين 1 ضد 1
- غرف من 6 أرقام وWebSocket لحظي.
- Durable Object مستقل لكل غرفة.
- 12 جولة بين الإجابة السرية والبازر والسرقة.
- السيرفر هو صاحب القرار في البازر والنقاط وحالة الجولة.
- إعادة اتصال تلقائية مع رمز reconnect محفوظ محليًا.
- أصوات البازر، بداية الجولة، الكشف، الصح والخطأ، ونهاية المباراة.

### السلم والثعبان — Premium
- 2 إلى 4 لاعبين محليًا أو أونلاين بالغرف.
- لوحة خشبية 1–100 باتجاه متعرج مع ثعابين وسلالم SVG فوق اللوحة بدل Emoji.
- قطع رخامية، نرد متحرك، وحركة متدرجة مع مؤثرات للصعود والهبوط.
- في الأونلاين السيرفر يولد النرد ويطبق الحركة؛ العميل يرسل أمر `roll` فقط.
- إعادة اتصال تلقائية مع حفظ المقعد ورمز reconnect.

### تحدي النرد
- 2 إلى 4 لاعبين.
- نمط «سباق النقاط»: استمر في الرمي أو ثبّت نقاطك قبل ظهور 1.
- نمط «أعلى رمية» بجولات قابلة للاختيار.
- مؤثرات رمي وحالة دور واضحة وشاشة فوز.

### الزهرة
- 2 إلى 4 لاعبين.
- أربعة أحجار لكل لاعب.
- الستة لإخراج الحجر، وخانات أمان، وأكل الخصم، ومسار نهاية خاص بكل لون.
- إنهاء الحجر يحتاج رقمًا دقيقًا، والفائز أول من ينهي أحجاره الأربعة.

### جاكارو — Premium
- 4 لاعبين بالضبط، فريقان: الأول + الثالث ضد الثاني + الرابع، محليًا أو أونلاين.
- أوراق لعب بدون جوكر، وتوزيع 4 / 4 / 5.
- A دخول أو 1/11، 4 للخلف، 5 لتحريك حجر مؤهل، 7 قابلة للتقسيم، J للتبديل، Q=12، K للدخول أو 13.
- اختيار الورقة ثم الحجر/الهدف مباشرة من اللوحة بدل قائمة حركات نصية طويلة.
- المحلي يحتفظ بشاشة خصوصية تمرير الجهاز، والأونلاين يرسل لكل لاعب يده فقط ويخفي هويات أوراق الخصوم على مستوى السيرفر.
- إعادة اتصال تلقائية، حالة اتصال لكل لاعب، وإعادة مباراة من الغرفة.
- فوز الفريق بعد إنهاء أحجار الشريكين الثمانية.

## نظام الصوت
`public/assets/js/audio-manager.js` هو المصدر الموحد للصوت في المنصة:
- مؤثرات موجودة من النسخة الأصلية حيث تناسب الحدث.
- مؤثرات Web Audio خفيفة للحركة والنرد والأوراق والسلالم والثعابين والبازر.
- تحكم مستقل بالمؤثرات وصوت المؤقت والاهتزاز ومستوى الصوت.
- الإعدادات محفوظة في `localStorage`.
- فك حظر الصوت على الجوال بعد أول تفاعل من المستخدم.

## الواجهة وPWA
- الصفحة الرئيسية أصبحت مركز ألعاب واحدًا باسم «بوسراج للألعاب».
- تصميم متجاوب للجوال والكمبيوتر.
- إعدادات صوت مشتركة.
- Service Worker يسبق تخزين صفحات الألعاب والمحركات والأصوات الأساسية.
- Manifest محدث باسم المنصة الجديدة.

## البنية التقنية
- Cloudflare Workers Static Assets للواجهة.
- `src/index.js` للـAPI وتوجيه غرف الأونلاين.
- `GameRoom` لتحدي العباقرة و`BoardGameRoom` المستقل لغرف السلم والثعبان وجاكارو.
- Durable Objects + SQLite-backed storage للغرف.
- WebSocket للتزامن اللحظي مع reconnect tokens.
- محركات الألعاب مستقلة داخل `public/assets/js/engines/`، ومنطق التحقق الأونلاين داخل `src/games/` و`src/rooms/`.

## الاختبارات
شغّل:

```bash
npm test
```

لفحص محركات السلم والثعبان، النرد، الزهرة، جاكارو، وملفات المنصة الأساسية.

وللتحقق الشامل قبل النشر:

```bash
npm run verify
```

هذا يشغّل الاختبارات، يتحقق من روابط الملفات المحلية، ثم ينفذ Cloudflare dry-run عبر Wrangler.

## النشر على Cloudflare
من جذر المشروع:

```bash
npm install
npx wrangler login
npm run verify
npm run deploy
```

المشروع مضبوط على Worker الحالي في `wrangler.jsonc`. لا ترفع مجلد `public` وحده إذا كنت تريد وضع الأونلاين؛ يجب نشر المشروع كاملًا لأن الغرف تعتمد على Worker + Durable Object.

بعد النشر افحص:

```text
/api/health
```

ويجب أن يرجع JSON فيه `ok: true` و`online: true`.

## ملاحظات الإصدار
- تحدي العباقرة المحلي والأونلاين بقي على نظامه الحالي دون إدخال منطق ألعاب الطاولة داخل `GameRoom`.
- السلم والثعبان يدعم الآن المحلي + أونلاين لـ2–4 لاعبين.
- جاكارو يدعم الآن المحلي + أونلاين لـ4 لاعبين بنظام 2v2، مع خصوصية اليد على مستوى السيرفر.
- الزهرة وتحدي النرد يظلان محليين في هذا الإصدار.
- `BOARD_ROOMS / BoardGameRoom` مضاف كـDurable Object منفصل مع migration `v2`.
