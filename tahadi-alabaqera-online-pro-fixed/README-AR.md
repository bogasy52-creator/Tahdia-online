# تحدي العباقرة — بوسراج | LOCAL + ONLINE

هذه النسخة تجمع وضعين مختلفين في مشروع Cloudflare Worker واحد:

## 1) اللعب المحلي
- نفس نظام الفئات والنقاط على جهاز واحد.
- 23 فئة و207 أسئلة.
- أصوات وزوم ومساعدات وتشكيل عشوائي.

## 2) التحدي الأونلاين 1 ضد 1
- إنشاء غرفة برقم 6 خانات.
- رابط دعوة مباشر.
- لاعبان فقط في كل غرفة.
- المضيف يختار 6 فئات أو يطلب فئات عشوائية.
- Ready لكل لاعب قبل البداية.
- 12 جولة: بالتناوب بين:
  - إجابة سرية: الطرفان يختاران بدون معرفة جواب الخصم.
  - مواجهة بازر: أول ضغطة يحجز الإجابة، وإذا أخطأ تنتقل فرصة سرقة.
- السيرفر يقرر أول ضغطة ويحسب النقاط.
- نقاط سرعة حتى +50 فوق قيمة السؤال.
- مساعدات لكل لاعب مرة واحدة:
  - دبل: مضاعفة نقاط السؤال عند الإجابة الصحيحة.
  - +7 ثوانٍ.
  - تعطيل: يمنع الخصم من استخدام مساعدة خلال الجولة.
- إعادة اتصال تلقائية عند انقطاع الشبكة.
- رمز reconnect سري محفوظ محليًا، فلا يفقد اللاعب مقعده عند تحديث الصفحة.
- إذا فتح نفس اللاعب اتصالًا ثانيًا، الاتصال الأقدم يُغلق.

## البنية
- Cloudflare Workers Static Assets للواجهة.
- Durable Object واحد لكل غرفة.
- SQLite-backed Durable Objects.
- WebSocket Hibernation API للتزامن اللحظي.
- حالة السؤال والإجابة الصحيحة والنقاط محفوظة في السيرفر، وليست في صفحة اللاعب.

## النشر على Cloudflare
المشروع مضبوط على اسم Worker:
`wild-scene-db78`

وهذا مناسب لتحديث رابطك الحالي إذا كان هذا هو اسم الـWorker الموجود في حسابك.

من داخل مجلد المشروع:

1. ثبّت Node.js.
2. افتح Terminal في هذا المجلد.
3. شغّل:
   `npm install`
4. سجّل الدخول:
   `npx wrangler login`
5. اختبر محليًا:
   `npm run dev`
6. انشر:
   `npm run deploy`

Wrangler سيقوم برفع ملفات الواجهة وإنشاء Durable Object SQLite وربطه بالـWorker.

## ملاحظة مهمة
السحب والإفلات لملفات HTML وحدها لا يكفي لنسخة الأونلاين؛ يجب نشر المشروع كاملًا عبر Wrangler لأن الغرف تحتاج Worker + Durable Object.

## المجانية
Durable Objects متاحة على Workers Free مع SQLite. عند تجاوز حدود الخطة المجانية اليومية تتوقف العمليات الزائدة حتى إعادة تعيين الحد، لذلك النسخة مناسبة للبدء والتجربة وعدد معقول من المباريات.

## فحص سريع إذا ظهر Load failed
افتح `/api/health` على نفس رابط Worker. يجب أن يرجع JSON فيه `ok: true` و`online: true`. إذا لم يحدث ذلك، فمحرك الغرف لم يُنشر. الواجهة الآن تفحص هذا تلقائيًا وتعطي رسالة واضحة.
