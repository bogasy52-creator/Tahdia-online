# بوسراج للألعاب — Snake PRO V9 · 9.0.0

نسخة مصدرية محدثة للثعبان والسلالم، مع الجاكارو والزهرة وتحدي النرد والألعاب الأخرى والسيرفر والمتجر الموجودين في المشروع. راجع START-HERE-AR.txt للتشغيل، وCLEANUP-V9-AR.md لتفاصيل التنظيف، وVERIFIED_V9_AR.md للفحوص الفعلية.

## التشغيل

استخدم Node.js 24 داخل مجلد snake_pro_v9:

```bash
npm run start:local
```

افتح http://localhost:4173. الألعاب المحلية وتقدم الضيف لا تحتاج تثبيت مكتبات. أبقِ الخادم يعمل، ولا تفتح HTML مباشرة بصيغة file://؛ محركات الألعاب تستخدم JavaScript modules. بعد أول تحميل ناجح، يتولى Service Worker تخزين ملفات الألعاب المحلية والأصوات والرسومات.

الحسابات والغرف والمواجهات تحتاج سيرفر المشروع:

```bash
npm ci --include=dev
npm run verify:release
npm run dev
```

النشر على Cloudflare موضح في DEPLOY-AR.txt. المشروع تطبيق ويب/PWA؛ الحزمة لا تتضمن APK.

## الثعبان والسلالم

اللوحة من ١٠٠ خانة، و٨ ثعابين و٨ سلالم. يرسم Canvas رؤوس المخلوقات بنسبة أبعادها الأصلية، وأجسامًا تحمل تفاصيل القشور من الرسم الأصلي. يتحدد طول الجسم وسماكته من المسافة بين رأسه وذيله. أرقام الخانات ومؤشرات النزول فوق الرسم لتبقى مقروءة.

حركة الثعبان تتضمن تموجًا هادئًا، اقتراب الرأس، ابتلاع الحجر، انتفاخًا ينتقل على الجسم، نموًا مؤقتًا واهتزازًا، ثم إطلاق الحجر عند الذيل والعودة إلى الحجم الطبيعي. مؤقت اكتمال الحركة مستقل عن إطارات Canvas ويدعم الإيقاف والمتابعة.

في كلا الوضعين تحتاج ٦ للدخول إلى الخانة ١، ويمنح الرقم ٦ رمية إضافية. يجب الوصول إلى ١٠٠ بالرقم الدقيق. الوقوف على رأس الثعبان ينقلك إلى ذيله، والسلم يصعدك إلى نهايته.

| الوضع | القواعد |
|---|---|
| كلاسيكي | ثعابين وسلالم وشرط الدخول بـ٦ والوصول الدقيق |
| مطوّر | القواعد نفسها مع نرد مكافآت عند الوقوف على ١٢ أو ٤٦ أو ٨٢ فقط |

| وجه نرد المكافآت | النتيجة |
|---|---|
| الحماية | تمنع ابتلاعًا واحدًا تلقائيًا؛ لا تتكدس أكثر من حماية واحدة |
| دوران إضافيان | رصيد دورين إضافيين؛ رمية ٦ لا تستهلك هذا الرصيد |
| نردان | قدرة واحدة لرمي نردين بعد الدخول؛ الحد الأقصى قدرتان |
| تقدّم ٣ | ثلاث خانات إضافية؛ تحل قواعد الثعبان والسلم في الوجهة |
| تقدّم ٥ | خمس خانات إضافية؛ تحل قواعد الثعبان والسلم في الوجهة |
| التجميد | يتخطى اللاعب التالي دورًا واحدًا |

المطوّر والبوتات متاحان في اللعب المحلي. الغرف تستخدم المحرك الكلاسيكي. مستويات البوت لا تغيّر احتمالات النرد؛ قيمة النرد تولّد باستخدام crypto.getRandomValues مع رفض العينات المنحازة. تحفظ الرمية والمكافأة قبل الحركة، ويحافظ الاستكمال على النتيجة نفسها.

## النرد والأصوات

مكعب بستة أوجه يدور ويرتد ثم يستقر على وجه كامل. نقاط أكبر وواضحة، مع إخفاء الأوجه الجانبية عند الاستقرار. نرد المكافآت مستقل وله ستة رموز مرسومة.

٢٠ مؤثرًا بصيغة WAV ستيريو، لحركة النرد وارتطامه والخطوات والسلالم والهجوم والابتلاع والنمو والأوراق والفوز. مدير الصوت المشترك يستخدم المجموعة الجديدة ويدعم كتم الصوت ومستوى الصوت وإعدادات المؤقت. scripts/render-arena-audio.py يعيد توليد الملفات باستخدام Python وNumPy وSciPy؛ تشغيل اللعبة لا يحتاج هذه المكتبات.

## باقي المشروع

الجاكارو يحتفظ بطاولة الخشب والمعدن وأحجاره وأوراقه وحركاته القانونية والبوتات. الزهرة وتحدي النرد والمتجر والهدايا اليومية والعملات وحسابات المستخدمين موجودة أيضًا. تقدم الضيف والجولات المحلية يبقيان في المتصفح؛ الحساب والغرف والمكافآت الموثقة تحتاج تشغيل السيرفر.

## الفحص

```bash
npm run verify:release
node scripts/verify-worker-config.mjs
```

فحص الإصدار يشمل اختبارات القواعد ومحاكاة الواجهات والسيرفر، وصحة JavaScript ومراجع الملفات وقائمة التخزين دون اتصال. SHA256SUMS.txt يحتوي بصمات ملفات الحزمة.

اختبارات المتصفح الاختيارية تحتاج Playwright وChromium:

```bash
npm run test:browser
npm run test:motion
npm run test:offline
```

تدعم السكربتات PLAYWRIGHT_CHROMIUM_EXECUTABLE وPRO_QA_OUTPUT. أزيلت سجلات الإصدارات القديمة من الحزمة المخففة. نتائج V9 السابقة وحدودها في VERIFIED_V9_AR.md، وفحص هذه الحزمة في CLEANUP-V9-AR.md.
