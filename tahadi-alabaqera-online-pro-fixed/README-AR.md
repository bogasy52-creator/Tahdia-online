# بوسراج للألعاب — SOCIAL PLATFORM 3.0

منصة ألعاب عربية تعمل محليًا وأونلاين على Cloudflare Workers وDurable Objects. الإصدار 3.0 يحافظ على تجربة 2.5 ويضيف حسابات دائمة، أصدقاء، Presence لحظي، إشعارات ودعوات دخول مباشر إلى غرف اللعب.

## الحسابات والأصدقاء 👥
- حساب دائم باسم مستخدم فريد واسم عرض يدعم العربية.
- كلمات المرور محمية بـ PBKDF2-SHA256 مع Salt، والجلسات لا تُخزن بصورتها السرية على السيرفر.
- طلبات صداقة، قبول/رفض، حذف، حظر وإلغاء حظر.
- Presence لحظي Online/Offline عبر `SocialUser` Durable Object وWebSocket Hibernation.
- إعدادات خصوصية للدعوات وإخفاء حالة الظهور.
- دعوة صديق مباشرة من لوبي تحدي العباقرة وجاكارو وسباق الـ100 والزهرة.
- السيرفر يتحقق من وجود الغرفة ونوع اللعبة وأن المباراة لم تبدأ قبل تسليم الدعوة.
- صفحة `/social` تجمع الحساب والأصدقاء والطلبات والإشعارات والإعدادات.

## تجربة الجوال 🎮
- سباق الـ100 والزهرة وجاكارو وتحدي النرد تدخل وضع لعب مخصص للجوال بعد بدء المباراة.
- اللوحة تظهر أولًا بعرض الشاشة، بينما تتحول معلومات اللاعبين والنرد والأزرار إلى Dock سفلي مضغوط.
- شريط الأونلاين وزر الإعادة يستخدمان صفًا محجوزًا خارج اللوحة ولا يغطيان الخانات.
- القواعد والشروحات الثانوية تختفي أثناء المباراة على الجوال لتوفير المساحة.
- تخطيط Landscape مستقل للهواتف القصيرة.
- أحجار سباق الـ100 أصبحت في طبقة أعلى من الثعابين والسلالم، مع حركة Glide فعلية بين الخانات.
- أحجار الزهرة تتحرك فوق اللوحة، والحجر المأكول يعود للبيت بحركة واضحة.
- أحجار جاكارو تتحرك في التقدم والتبديل وتقسيم 7 بدل القفز الفوري.
- منطقة الانطلاق في سباق الـ100 أصبحت Overlay صغيرة داخل اللوحة بدل استهلاك مساحة رأسية.

## تحدي العباقرة 🧠
- **23 فئة و687 تحديًا** في بنك واحد مشترك بين المحلي والأونلاين.
- الفئات النصية تحتوي على 27 سؤالًا على الأقل لكل فئة، موزعة على 100/200/300.
- **60 تحديًا صوتيًا** محليًا، 20 لكل مستوى، وبحد أقصى تشغيلين للسؤال لتحقيق العدالة.
- **60 تحدي صور فوتوغرافية محلية** بصيغة WebP، مع نقطة تركيز خاصة ومراحل Zoom/Kickback محسوبة.
- الصور لا تعتمد على روابط صور خارجية أثناء اللعب.
- ملفات الصوت تمت تسويتها إلى مستوى متقارب فعليًا؛ يوجد `assets/sounds_pro/manifest.json` ببصمة SHA256 وقياسات كل مقطع.
- خيارات الإجابة الخاطئة منسقة حسب نوع السؤال بدل خلط إجابات غير منطقية: دول مع دول، سنوات مع سنوات، أرقام مع أرقام، مصطلحات تقنية مع مصطلحات تقنية… إلخ.
- لا يوجد تكرار نصي مطابق في الأسئلة النصية، ولكل سؤال ID ثابت ومستوى ونوع إجابة.
- منع تكرار الأسئلة الحديثة بين المباريات، وخلط Fisher–Yates في المحلي.
- الأونلاين يدعم 12 / 18 / 24 جولة، مع توزيع Secret/Buzzer متوازن.
- واجهة الصوت تعرض Waveform/Progress حقيقيين وتمنع تشغيل أكثر من مقطع في الوقت نفسه.

## النرد والأحجار 🎲
- نرد Porcelain أبيض/لؤلؤي بنقاط سوداء كبيرة وعميقة وواضحة.
- دوران مرتب على أرباع 90° بدل دوران بصري فوضوي.
- حركة: ارتفاع → انقلاب → ارتطام → Bounce صغير → Snap نهائي.
- ظل يتغير مع ارتفاع النرد، صوت Porcelain متعدد المراحل، واهتزاز متزامن عند الأجهزة الداعمة.
- النرد المشترك مستخدم في السلم والثعبان والزهرة وتحدي النرد.
- أحجار السلم والثعبان والزهرة وجاكارو أصبحت Pawns منحوتة ذات رأس/جسم/قاعدة وظلال ولمعة واضحة.

## الأونلاين والحماية 🔐
- السيرفر authoritative في الرميات والحركات الحساسة.
- منع دخول الضيف كمضيف بدون `hostKey` صحيح.
- `hostKey` وReconnect token لا يوضعان في WebSocket URL.
- Origin validation بدل `CORS *`، وRate limiting لإنشاء/فحص الغرف ومحاولات WebSocket.
- مهلة سماح للانقطاع، نقل استضافة تلقائي، تنظيف غرف منتهية، وعودة Rematch للّوبي والجاهزية.
- ألعاب اللوح لديها Turn timeout ومعالجة عند انقطاع صاحب الدور.
- جاكارو: أوراق الخصوم masked، وورقة 7 تدعم سبعة كاملة على حجر واحد أو التقسيم.
- أسماء اللاعبين يتم تنظيفها وEscape قبل عرضها في واجهات تعتمد HTML ديناميكيًا.

## PWA والوسائط
- App shell cache: **`busraj-games-v14`**.
- Quiz media cache: **`busraj-quiz-media-v3`**.
- صور وأصوات تحدي العباقرة الكبيرة تُخزن Lazy Cache لتجنب تضخيم تثبيت الـService Worker.
- الوسائط الأساسية محلية، لذلك لا تتوقف أسئلة الصور بسبب موقع صور خارجي.

## النشر على Cloudflare

```bash
npm install
npx wrangler login
npm run verify
npm run deploy
```

بعد النشر افتح:

```text
/api/health
```

ويجب أن تتضمن الاستجابة:

```text
ok: true
online: true
quizOnline: true
boardOnline: true
socialOnline: true
version: "3.0.1"
```

> لا تنشر مجلد `public` وحده؛ انشر المشروع كاملًا لأن Worker وDurable Objects جزء من الأونلاين.
