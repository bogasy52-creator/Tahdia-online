# بوسراج للألعاب — Snake PRO V11 · 11.0.2

نسخة مصدرية محدثة للثعبان والسلالم، مع الجاكارو والزهرة وتحدي النرد والألعاب الأخرى والسيرفر ومتجر جديد للمقتنيات والمهمات وإدارة حساب bosrag. راجع START-HERE-AR.txt للتشغيل، وCLEANUP-V9-AR.md لتفاصيل التنظيف، وVERIFIED_V11_AR.md للفحوص الفعلية.

## التشغيل

استخدم Node.js 24 داخل مجلد snake_pro_v11_2:

```bash
npm run start:local
```

افتح http://localhost:4173. الألعاب المحلية وتقدم الضيف لا تحتاج تثبيت مكتبات. أبقِ الخادم يعمل، ولا تفتح HTML مباشرة بصيغة file://؛ محركات الألعاب تستخدم JavaScript modules. بعد أول تحميل ناجح، يتولى Service Worker تخزين ملفات الألعاب المحلية والأصوات والرسومات.

الحسابات والغرف والمواجهات تحتاج سيرفر المشروع:

```bash
npm ci --include=dev
npm run verify:release
npm run dev
```

النشر على Cloudflare موضح في DEPLOY-AR.txt. المشروع تطبيق ويب/PWA؛ الحزمة لا تتضمن APK.

## الثعبان والسلالم

اللوحة من ١٠٠ خانة، و٨ ثعابين و٨ سلالم. يرسم Canvas رؤوس المخلوقات بنسبة أبعادها الأصلية، وأجسامًا تحمل تفاصيل القشور من الرسم الأصلي. يتحدد طول الجسم وسماكته من المسافة بين رأسه وذيله. أرقام الخانات مطبوعة مباشرة على البلاطات دون خلفيات أو علامات نزول صغيرة. رؤوس الثعابين ومساراتها متباعدة؛ انتقل الذهبي إلى ٦٨ وينزل إلى ٥٠، لتفادي تقاطعه مع الأزرق. تظل أرقام النهاية متاحة عند الضغط على الخانة.

حركة الثعبان تتضمن تموجًا هادئًا، اقتراب الرأس، ابتلاع الحجر، انتفاخًا ينتقل على الجسم، نموًا مؤقتًا واهتزازًا، ثم إطلاق الحجر عند الذيل والعودة إلى الحجم الطبيعي. مؤقت اكتمال الحركة مستقل عن إطارات Canvas ويدعم الإيقاف والمتابعة.

في كلا الوضعين تحتاج ٦ للدخول إلى الخانة ١، ويمنح الرقم ٦ رمية إضافية. يجب الوصول إلى ١٠٠ بالرقم الدقيق. الوقوف على رأس الثعبان ينقلك إلى ذيله، والسلم يصعدك إلى نهايته.

| الوضع | القواعد |
|---|---|
| كلاسيكي | ثعابين وسلالم وشرط الدخول بـ٦ والوصول الدقيق |
| مطوّر | القواعد نفسها مع نرد مكافآت عند الوقوف على ١٢ أو ٤٦ أو ٨٢ فقط |

| وجه نرد المكافآت | النتيجة |
|---|---|
| الحماية | تمنع ابتلاعًا واحدًا تلقائيًا؛ لا تتكدس أكثر من حماية واحدة |
| دوران إضافيان | رصيد دورين إضافيين؛ رمية ٦ لا تستهلك هذا الرصيد |
| نردان | قدرة واحدة لرمي نردين بعد الدخول؛ الحد الأقصى قدرتان |
| تقدّم ٣ | ثلاث خانات إضافية؛ تحل قواعد الثعبان والسلم في الوجهة |
| تقدّم ٥ | خمس خانات إضافية؛ تحل قواعد الثعبان والسلم في الوجهة |
| التجميد | يتخطى اللاعب التالي دورًا واحدًا |

منذ 33.0.0 تُلعب الثعبان والسلالم والزهرة وجاكارو وتحدي النرد أونلاين فقط: «العب الحين» يفتح طاولة عامة تبدأ بعد 10 ثوانٍ، والغرفة الخاصة تبدأ بمن حضر، والمقاعد الفاضية يكملها السيرفر ببوتات من ثلاثة مستويات. الكلاسيك (عادي) والمطوّر يُختاران من القائمة قبل الدخول، وتظهر القواعد للجميع في الانتظار. يولّد السيرفر النرد العادي والمزدوج ونرد المكافآت، ويحفظ الحماية والأدوار والقدرات. يظهر نرد المكافآت تلقائيًا لدى لاعبي الغرفة، وتعود الغرفة إلى الأسلوب نفسه بعد إعادة المباراة. البوتات يشغّلها السيرفر بمستويات مختلفة داخل الطاولة نفسها. مستويات البوت لا تغيّر احتمالات النرد؛ قيمة النرد تولّد باستخدام crypto.getRandomValues مع رفض العينات المنحازة. تحفظ الرمية والمكافأة قبل الحركة، ويحافظ الاستكمال على النتيجة نفسها.

## المتجر والمكافآت

خزانة الحلبة تضم ٤٢ إضافة في ٨ أنواع: أحجار، نرد، ثعابين، حلبات، طاولات، آثار حركة، احتفالات فوز وألقاب. منها ٨ إضافات أساسية مجانية، و٣٢ مدفوعة بالعملات، ولقب إنجاز حصري ولقب المدير. تظهر الإضافات بعد التجهيز داخل الألعاب، ومعاينات النرد تستخدم المكعب الفعلي ومعاينات الثعابين تستخدم طلاء القشور نفسه.

ثلاث مجموعات: المفاعل، الشفق والتتويج. خصم المجموعة ٢٥٪ على القطع غير المملوكة فقط، ويُحتسب بعد عرض اليوم. شراء المجموعة يجهّز كل قطعها. المقتنيات تشمل تجهيز القطع المملوكة، والبحث والترتيب وتحديد هدف ادّخار منفصل لكل حساب. عند انتهاء العرض أو تغيّر القطع الناقصة يُرفض السعر القديم وتُحدّث المعاينة قبل إعادة الشراء.

| المصدر | المكافآت |
|---|---|
| الجولة المحلية المكتملة | ٢٠ عملة للفوز أو ٨ للمشاركة؛ أول ٢٠ جولة يوميًا |
| المباراة الموثّقة | ٥٠ عملة للفوز أو ١٥ للمشاركة |
| هدية الدخول | من ٣٠ إلى ١٢٠ عملة مع الحضور المتتابع |
| ثلاث مهمات يومية | حتى ١١٠ عملات إضافية |
| ثلاث مهمات أسبوعية | حتى ٤١٠ عملات إضافية |
| ستة إنجازات دائمة | عملات إضافية ولقب أسطورة النيون عند ٥٠ جولة |

يبدأ اليوم عند منتصف الليل بالرياض، والأسبوع يوم الاثنين. كل مهمة تُستلم مرة واحدة في فترتها. الأونلاين يُحتسب من نتائج السيرفر فقط؛ نتائج التدريب لا ترفع الرتبة. نتائج محلية تنتظر المزامنة لا تتقدم مهماتها حتى يعتمدها السيرفر. لا تشتري الإضافات قوة أو احتمالات نرد أفضل.

## مدير الحلبة BoSraG

اسم BoSraG أو bosrag يشير إلى الحساب نفسه، حتى في الجلسات القديمة. تُعرض حالة الإدارة في الرئيسية والمتجر والحساب، مع تمييز المدير الموثّق عن السيرفر القديم أو الجلسة المنتهية. صلاحيات المدير تُفحص مستقلة عن مزامنة العملات.

بعد نشر **الحزمة كاملة بما فيها السيرفر**، يدخل صاحب الحساب bosrag بكلمة مروره المعتادة. تظهر له الإدارة من الرئيسية والمتجر والحساب، أو على /admin. الصلاحيات مستخرجة من الحساب الموثّق؛ الاسم الظاهر أو تعديل بيانات المتصفح لا يمنح إدارة.

يفتح السيرفر جميع المقتنيات الحالية والجديدة لهذا الحساب تلقائيًا، ويحافظ على رصيده وخبرته وتجهيزاته. لا يُنشأ حساب جديد ولا تُغيَّر كلمة المرور. لقب مدير الحلبة محصور بالحساب الموثّق.

اللوحة تعرض الحساب بالاسم الإنجليزي، وتدير إضافة العملات أو خصمها، إضافة خبرة التقدم، فتح مقتنى أو فتح المجموعة كاملة للاعب، إيقاف الحساب وإعادته وإنهاء جلسات دخوله، ونشر إعلان أو إزالته. يظهر الإعلان في الرئيسية والمتجر. لكل عملية سجل وسبب اختياري ورقم يمنع تكرارها عند انقطاع الاتصال. العودة لطلب قديم تعرض الرصيد الحالي ولا تعيد المكافأة. إيقاف الحساب لا يحذف تقدمه؛ حساب المدير محمي من إيقاف نفسه. خبرة المدير لا تزوّر رتبة الأونلاين.

لم يُطبَّق هذا التحديث على خدمة منشورة في هذه الجلسة. صلاحيات الحساب الحي تتفعّل عند تحديث Worker والأصول معًا. المعاينة المحلية الثابتة لا توفر الحسابات أو لوحة الإدارة.

## تصحيح استهلاك الأونلاين 11.0.2

رسالة Exceeded allowed volume of requests in Durable Objects free tier تعني تجاوز حصة Cloudflare اليومية. الحدود المجانية تُعاد الساعة 00:00 UTC، أي ٣ صباحًا في السعودية. رفع ملفات جديدة وحده لا يعيد الحصة المستهلكة.

أُصلح مؤقت غرفة مهجورة كان يعيد جدولة نفسه بعد ٥٠ مللي ثانية عندما تنتهي مهلة المضيف ولا يوجد بديل متصل. ينتظر الآن انتهاء الغرفة مع الاحتفاظ بحق الرجوع، وتبقى مهلة الـ٤٥ ثانية وانتقال المضيف للاعب متصل. تنظيف طابور المواجهة يُجدول عند انتهاء التذاكر ويتوقف بعد فراغه.

عند بلوغ الحصة تظهر رسالة عربية وموعد إعادة الضبط بدل اتهام محرك الغرف بأنه قديم. يتوقف العامل عن إعادة طلب المحركات في النسخة الجاري تشغيلها حتى إعادة الضبط، ويتوقف فحص العميل الإضافي وتكرار طلبات المواجهة عند هذا الخطأ. الحد نفسه يخص الحساب، ولا يمكن للكود تجاوزه.

بعد تثبيت المكتبات، يشغّل الأمر التالي اختبارًا فعليًا محليًا بمحرك workerd وتخزين SQLite واتصالات WebSocket، ولا يحتاج تسجيل دخول إلى Cloudflare:

```bash
npm run test:cloudflare
```
