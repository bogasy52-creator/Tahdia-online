بوسراج للألعاب 2.0 — طريقة النشر

1) فك الملف ZIP.
2) افتح Terminal داخل المجلد الذي يحتوي package.json وwrangler.jsonc.
3) نفذ: npm install
4) نفذ: npx wrangler login
5) نفذ: npm run verify
6) إذا انتهى التحقق بدون أخطاء نفذ: npm run deploy

بعد النشر افتح رابط Worker ثم /api/health.
المفترض يظهر JSON فيه ok:true و online:true.

مهم جدًا:
- لا ترفع public وحده؛ الأونلاين يحتاج Worker + Durable Object.
- الصفحة الرئيسية الآن هي مركز الألعاب.
- الألعاب الجديدة (جاكارو، الزهرة، السلم والثعبان، النرد) محلية على نفس الجهاز في هذا الإصدار.
- تحدي العباقرة يحتفظ بالوضع المحلي والأونلاين.
