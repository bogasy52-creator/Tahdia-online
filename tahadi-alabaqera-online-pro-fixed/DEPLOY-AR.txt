بوسراج للألعاب 2.0 — طريقة النشر

1) فك الملف ZIP.
2) افتح Terminal داخل المجلد الذي يحتوي package.json وwrangler.jsonc.
3) نفذ: npm install
4) نفذ: npx wrangler login
5) نفذ: npm run verify
6) نفذ: npm run verify:full  (يتطلب تثبيت Wrangler عبر npm install)
7) إذا انتهى التحقق الكامل بدون أخطاء نفذ: npm run deploy

بعد النشر افتح رابط Worker ثم /api/health.
المفترض يظهر JSON فيه ok:true و online:true.

مهم جدًا:
- لا ترفع public وحده؛ الأونلاين يحتاج Worker + Durable Objects.
- Worker يبقى بنفس الاسم: tahdia-online.
- Durable Objects الحالية:
  ROOMS / GameRoom لتحدي العباقرة.
  BOARD_ROOMS / BoardGameRoom للسلم والثعبان وجاكارو.
- migration v2 تضيف BoardGameRoom، لذلك يجب نشر المشروع كاملًا عبر Wrangler.
- السلم والثعبان: محلي + أونلاين لـ2–4 لاعبين.
- جاكارو: محلي + أونلاين لـ4 لاعبين 2v2 مع إخفاء يد الخصوم على مستوى السيرفر.
- الزهرة وتحدي النرد يظلان محليين.
- الصفحة الرئيسية هي مركز الألعاب.
