# تحدي العباقرة 17.0.0 — رحلة النجوم

إصدار يضيف لعبتين كاملتين داخل المشروع الحالي، ويربط التقدم والمكافآت بالحساب، ويحدّث عرض الألعاب والمتجر والثعابين.

## الألعاب والتقدم

- **وصل الجواهر:** 60 مرحلة في خمسة عوالم. توصيل 3 جواهر متجاورة من اللون نفسه، أفقيًا أو رأسيًا أو قطريًا، وتحقيق هدف مجموع الجواهر وهدف شكل/لون محدد خلال 20 حركة. سلسلة من 7 تمسح صفًا. كل مرحلة مجرّبة بسلاسل قانونية.
- **مسارات الألوان:** 60 مرحلة في خمسة عوالم. توصيل الأزواج المرقمة دون تقاطع وتغطية اللوحة بالكامل. لكل لوحة حل كامل مبني من مسار متصل. ثلاثة تلميحات كحد أقصى لكل محاولة.
- تحدٍّ يومي لكل لعبة، يتجدد عند منتصف الليل بتوقيت الرياض. نفس اللوحة لجميع اللاعبين في ذلك اليوم. يمكن إعادة المحاولة دون انتظار.
- نجمة إلى ثلاث نجوم، فتح متتابع للمراحل، وأفضل نتيجة محفوظة. الإعادة لا تكرر عملات المرحلة.
- لقب **صائد النجوم** عند 30 نجمة ولقب **سيّد المسارات** عند 120 نجمة من مراحل المغامرة. يظهران كمقتنيات حصرية قابلة للتجهيز في المتجر.
- الجولة غير المكتملة تُحفظ على جهازها. المراحل المكتملة تتزامن مع الحساب. نتائج الحساب المحفوظة عند انقطاع الاتصال تنتظر المزامنة؛ نتيجة التحدي اليومي تُقبل في يومها أو اليوم التالي فقط.
- مكافآت الجولات والمهمات تستخدم نظام الحساب الحالي وحد التدريب اليومي: أول 20 جولة. نجوم المراحل تستمر بعد الحد. نتائج المراحل لا تمنح نقاط رتبة الأونلاين.

## الواجهة والمتجر والحلبة

الرئيسية تعرض تحديات اليوم والتقدم وألعاب المراحل. أُضيفت أغلفة مرسومة للألعاب ونظام ألوان ومسافات وأزرار موحد، وروابط للمراحل من صفحات اللعب.

بطاقات المتجر تعرض الإضافة والسعر والسلة والمعاينة بشكل أبسط. الشراء الفردي من شاشة المعاينة، وشراء السلة مع مراجعة الإجمالي. معاينات البطاقات تُرسم قرب ظهورها على الشاشة، وتبقى المعاينة الحية وتجربة الثعبان داخل التدريب. هدف الادخار ضمن تفاصيل البطاقة.

ست خامات مختلفة لأجسام الثعابين: نقشة أفعى، أشرطة شفقية، دروع كوبرا، بلورات، حراشف وتعرجات، ودوائر بلازما. الرسم نفسه مستخدم في المتجر والحلبة. حافظ التحديث على التحكم الحر وقوانين الافتراس والفيزياء المثبتة.

## التحميل والتشخيص

استُبدل التنزيل المسبق الكبير بنواة صغيرة للرئيسية ورحلة النجوم. تُخزّن بقية الألعاب والأصول عند زيارتها. حُفظت الصور الأصلية وأضيفت نسخ أخف للاستخدام، وأصبح تحميل الرسومات بحسب نوع الإضافة.

ملف تنسيق مجمّع لكل صفحة، مع مصادر محفوظة وقابلة لإعادة البناء:

```sh
node scripts/build-styles.mjs
node scripts/build-offline.mjs
```

التقاط محدود للأخطاء غير المعالجة وإرسالها إلى سجل Worker عند الاتصال. دون مفاتيح أو خدمة خارجية أو ربط قاعدة بيانات جديدة. لا تُسجّل رموز الجلسة أو عناوين الاستعلام، وتُحدّد أحجام الرسائل ومعدلها.

## التشغيل والتحقق

بعد تطبيق الباتش على المشروع:

```sh
npm ci
npm run dev
```

التشغيل المحلي يدعم الألعاب الفردية. الحسابات والغرف تحتاج تشغيل Worker. فحوص الإصدار:

```sh
npm run verify:release
npm run test:cloudflare
npm run check:cloudflare
```

الأمر الأخير بناء تجريبي `--dry-run`. النشر الفعلي يظل من إعداد مشروعك المعتاد. لا تغييرات مطلوبة على اسم Worker أو الرابط أو الروابط البرمجية أو الترحيلات.

الاختبارات الآلية وCanvas ومحاكاة Cloudflare لا تغني عن تجربة آيفون وأندرويد والمتصفحات والشبكات الفعلية. لا يتضمن هذا التسليم شهادة انعدام الأخطاء أو اختبار حمل إنتاجي على مستخدمين حقيقيين.
