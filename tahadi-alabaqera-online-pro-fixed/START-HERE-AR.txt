Snake PRO V7 — 7.0.0

1. فك الملف وافتح مجلد snake_pro_v7.
2. تأكد أن Node.js 24 مثبت.
3. افتح الطرفية في المجلد ونفذ:
   npm run start:local
4. افتح الرابط:
   http://localhost:4173

الثعبان والجاكارو والزهرة والنرد والمتجر متاحة محليًا.
على Windows يمكنك تشغيل START-LOCAL.cmd.
اختر نمط المنافسة ومستوى البوت ثم ابدأ.
المغامرة في الثعبان تضيف الدرع والنرد المزدوج والأحداث.
من الرئيسية يمكنك استلام الهدية اليومية ومتابعة العملات والمستوى.
التقدم والجولة المحلية محفوظان تلقائيًا على المتصفح نفسه.
إذا حدث تحديث أثناء رمي النرد، استخدم زر متابعة الجولة السابقة.

الحسابات والغرف والمواجهات تحتاج سيرفر المشروع:
   npm ci --include=dev
   npm run dev

README-AR.md يشرح الميزات والقواعد.
DEPLOY-AR.txt يشرح النشر على Cloudflare.
VERIFIED_V7_AR.md يعرض الاختبارات المنفذة.
