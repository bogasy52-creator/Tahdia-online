Snake PRO V12 — المتجر وحلبة الثعابين — 12.0.0

1. فك ZIP وافتح مجلد snake_pro_v12.
2. استخدم Node.js 24.
3. للتشغيل المحلي: npm run start:local
4. افتح http://localhost:4173
5. للتشغيل مع الحسابات والغرف: npm ci --include=dev ثم npm run dev

حلبة الثعابين الجديدة: افتح /serpent أو اخترها من الرئيسية.
- فردي مع 2 أو 4 أو 6 بوتات وثلاث صعوبات.
- لاعبان على الجهاز نفسه مع شاشتين وعصي لمس مستقلة.
- غرف أونلاين خاصة من لاعبين إلى 8 لاعبين حقيقيين.
- الكل يضغط جاهز، ثم يبدأ المضيف الجولة.
- أكل الطاقة يزيد الحجم؛ التسريع يستهلك الحجم.
- الرأس يصطدم بجسم الخصم أو الحدود فتخرج من الجولة.
- اصطدام الرأسين يفوز فيه الأكبر إذا زاد حجمه 25%، وإلا يخرج الاثنان.
- الثعبان المنهزم يترك طاقة قابلة للأكل. البوتات تظهر بوسم BOT وتعود بعد 3 ثوانٍ.
- عند نهاية الجولة تفوز أعلى طاقة بين الثعابين الحية؛ البوتات تُقارن فعلًا في الفردي.
- الجوال: عصا الحركة وزر التسريع. الكمبيوتر: الماوس أو الأسهم وSpace.
- للاعب الثاني: WASD وShift.
- بعد إعادة تحميل الصفحة اضغط «ارجع إلى غرفتك السابقة».

المتجر:
- ستة أشكال ثعابين مختلفة فعليًا، ومعاينات للأحجار والنرد والحلبات والطاولات.
- افتح «استعرض الإضافة» لمعاينة كبيرة قبل شراء أو تجهيز أي شيء.
- المهمات اليومية والأسبوعية والمجموعات والمقتنيات موجودة وتستخدم الرصيد الحقيقي.
- مظاهر الثعابين والأحجار المجهزة تظهر أيضًا في ألعاب اللوحة.

BoSraG:
سجل دخولك بحسابك الحالي؛ حقوق المدير ومقتنياته محفوظة وتتحقق من السيرفر.
لم تتغير أسماء Durable Objects أو الترحيلات السابقة.

النشر:
ارفع الحزمة كاملة — public وsrc وwrangler.jsonc وباقي المشروع — عبر npm run deploy.
نشر public وحده لا يحدّث محرك الجماعي أو صلاحيات الحسابات.
هذه الحزمة لم تُنشر إلى حسابك تلقائيًا.
إصلاح حصة الطلبات من V11.2 محفوظ. عند نفاد الحصة المجانية يعود الأونلاين ٣ صباحًا بالرياض.
