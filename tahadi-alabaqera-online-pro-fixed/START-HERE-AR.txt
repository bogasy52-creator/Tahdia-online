Snake PRO V10 NEON + ONLINE — 10.0.0

1. فك الملف وافتح مجلد snake_pro_v10.
2. استخدم Node.js 24.
3. افتح الطرفية في المجلد وشغّل:
   npm run start:local
4. افتح http://localhost:4173

على Windows يمكنك تشغيل START-LOCAL.cmd.
لا تفتح HTML مباشرة؛ اترك الخادم المحلي يعمل أثناء اللعب.

الثعبان:
- اختر الكلاسيكي أو المطوّر قبل البدء؛ الخياران موجودان أيضًا في إنشاء غرفة أونلاين.
- تحتاج رمية ٦ للدخول إلى الخانة ١؛ ثم تحصل على رمية إضافية.
- المطوّر فيه ثلاث خانات مكافآت فقط: ١٢، ٤٦، ٨٢.
- عند الوقوف عليها يظهر نرد رموز: حماية، دوران إضافيان، نردان،
  تقدّم ٣، تقدّم ٥، أو تجميد دور الخصم.
- الحماية تمنع ابتلاعًا واحدًا تلقائيًا، وقدرة النردين تستخدم بعد الدخول.
- الثعبان الذهبي صار من ٦٨ إلى ٥٠؛ المسارات الجديدة متباعدة والأرقام بلا خلفيات.
- اضغط على خانة ثعبان لمعرفة مكان نزوله.
- الجولات المحلية محفوظة تلقائيًا في المتصفح نفسه.

الجاكارو والزهرة وتحدي النرد والألعاب الأخرى موجودة في المشروع.
للأونلاين ارفع المشروع كاملًا، الواجهة والسيرفر معًا. نشر public وحده لا يضيف المطوّر للسيرفر القديم.
الحسابات والغرف والمواجهات تحتاج سيرفر المشروع:
   npm ci --include=dev
   npm run dev
