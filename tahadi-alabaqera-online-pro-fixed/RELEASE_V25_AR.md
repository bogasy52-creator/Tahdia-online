# تهدئة v25.0.0 — واجهة موحدة + اختيار الأصدقاء + احتفالات مرئية

## المنجز في هذه الحزمة

- طبقة تنسيق ليلية احترافية موحدة لصفحات الألعاب: تدرّج كحلي، لمسات تركواز وذهبي، مسافات وخطوط متجاوبة مع الهاتف، وتفادي التغطية على لوحة اللعب.
- شريط علوي ثابت يمكن الوصول إليه: زر رجوع، جميع الألعاب، صفحة الأصدقاء، ودعوة صديق من كل لعبة.
- نافذة الدعوة تستعلم عن الأصدقاء الحقيقيين لحساب اللاعب من `/api/social/me` وتسمح بإرسال دعوة فعلية من `/api/social/invites` في غرف الأونلاين المتاحة؛ مشاركة رابط اللعبة منفصلة. تتطلب حسابًا وصداقة وغرفة لا تزال تستقبل لاعبين. اللعب الفردي لا يملك إرسال دعوة غرف فعلية، وإنما مشاركة رابط التحدي.
- مؤثرات مرئية للنجاح/الخطأ على رسائل النتيجة وتراكب فخم عند الفوز، يظهر فيه اسم الفائز وتاج وقصاصات ملونة مع احترام خيار تقليل الحركة.
- سودوكو الأونلاين: عداد أخطاء 0/5 وتقييد إدخالات اللاعب في الواجهة بعد الخطأ الخامس؛ يتم احتساب الخطأ عند استلام قبول الحركة من السيرفر دون ارتفاع نقاط الإجابات الصحيحة. يستمر الحظر على الجهاز بعد إعادة تحميل الصفحة طوال نفس الجولة، ويُعاد ضبطه للجولة التالية. **هذا حد على العميل فقط** وليس حكمًا نهائيًا من السيرفر؛ ضمان العدل بين اللاعبين يتطلب تحديث `src/sudoku/sudoku-room.js` وهو غير موجود في أرشيف التحديث المتاح. لا تعتبر المنافسة خماسية الأخطاء معتمدة إنتاجيًا قبل استكمال السيرفر.
- يتم تفعيل التصميم على كل صفحات الألعاب عند تشغيل build عبر `scripts/apply-premium.mjs`، بما في ذلك صفحات `quiz` و`picture` غير الموجودة ضمن الأرشيف الجزئي. يجدد `build-offline.mjs` اسم الكاش ويضيف CSS/JS الأساسية.

## اختبارات أجريت

- `node --check` لملفات JS الجديدة والمعدّلة.
- متصفح Chromium لمحاكاة شاشة هاتف 390×760، فتح النافذة وإغلاقها بلوحة المفاتيح، استدعاء قائمة صديق (بيانات API اختبارية) وإرسال POST وهمي، والتحقق من عرض اسم الفائز.
- محاكاة تدفق WebSocket لسودوكو في Chromium: خمسة إدخالات خاطئة يؤكدها رد السيرفر تؤدي إلى منع الإدخال السادس محليًا.
- فحص تطابق بصمات SHA-256 لجميع الملفات المسلمة مقابل المانيفست، وفحص ضغط ZIP.

## حدود الفحص

لم يُشغّل الموقع الإنتاجي، ولم تُختبر الشبكة الحقيقية أو تعدد الأجهزة. جرى اختبار الواجهة والدعوات ببيانات API تجريبية، وليس إرسال دعوة لصديق فعلي. الأرشيف **تحديث جزئي تراكمي** ولا يحتوي المشروع الكامل. لعدم توفر شجرة مصدر 24.0.1 كاملة في هذه الجلسة، لم تُشغّل حزمة `npm test` الكاملة ولا اختبار Cloudflare `workerd` على المشروع الكامل. لا نضمن انعدام جميع المشاكل.

## طريقة التركيب

1. خذ نسخة احتياطية من مستودعك الحالي.
2. احذف ملف ZIP القديم من جذر المستودع وارفع هذا ZIP وحده، دون فكّه، إلى المستودع نفسه.
3. شغل أحدث `Auto Update Game` حسب خط سير مشروعك. لا تعد تشغيل job قديم.
4. شغّل `npm run verify:release` قبل الاعتماد والنشر. سيعيد بناء CSS والكاش ويضيف ملفات التصميم لكل الصفحات.
5. ارفع التحديث إلى موقع تجريبي، اختبر الآيفون وغرفة صديق حقيقية؛ لا تعتبر حد خسارة 5 أخطاء معتمدًا تنافسيًا حتى يتوفر تعديل السيرفر.

**التوافق مع المدخلات المعروفة:** 23.0.1، 24.0.0، 24.0.1، وإعادة التطبيق على 25.0.0. إذا كان بالمستودع تعديل مجهول لأحد الملفات المستهدفة يجب أن يرفض المثبّت التحديث قبل الاستبدال.
