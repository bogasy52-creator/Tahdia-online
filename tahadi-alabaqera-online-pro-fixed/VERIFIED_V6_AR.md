# تقرير التحقق — الإصدار 6.0.0

تاريخ الفحص: 10 أكتوبر 2026. البيئة: Node.js 24.19.0، اختبارات المحركات ومحاكاة Durable Objects وDOM داخل Node.

## النتائج المسجلة

| الفحص | النتيجة |
|---|---|
| npm run verify:release | ناجح |
| اختبارات Node | 177 إجمالًا: 171 نجاحًا، 0 فشل، 6 تجاوزات |
| فحص الأصول المحلية | 443 مرجعًا سليمًا |
| فحص Worker المحلي | نجاح المسارات وتهيئة الأصول وbindings وحماية المصدر |
| فحص إعداد Worker | نجاح ROOMS وBOARD_ROOMS وQUICK_ARENA وترحيل الفئة الجديدة |
| فحص صياغة JavaScript | 90 ملفًا، و9 سكربتات داخل HTML |
| كاش التطبيق | 220 مسارًا بلا تكرار، مع الصفحات والتبعيات الجديدة |
| مراجع الأصول داخل CSS | مرجع محلي واحد سليم |

الاختبارات الستة المتجاوزة تحتاج أدوات مستودع خارجي داخل .github/scripts في المجلد الأب، وهي غير موجودة في ZIP الأصلي: استيراد ZIP بأربع حالات، والعثور على ZIP، وتثبيت تبعيات سير تحقق خارجي. ليست اختبارات لعب متجاوزة. الفاحص المحلي لا يثبت صحة إعداد حساب Cloudflare المنشور.

## سلوكيات جرى تنفيذها واختبارها

- إنتاج 1000 لوحة Puzzle غير محلولة قابلة للوصول إلى الحل، ومنع عبور حدود الصفوف والفوز المبكر.
- تشغيل 100 مباراة ثعبان عشوائية كاملة بأربعة لاعبين دون الخروج من حدود اللوحة.
- رفض النقر المكرر أثناء حركة الثعبان، انتظار اللاعب الآلي، وعرض الفائز وتسجيل النتيجة مرة واحدة.
- بناء الجاكارو بمواقع المسار والأمان والمنازل كاملة، وتشغيل اختيار ورقة وحجر للدخول، ووصول الأحجار الثاني والثالث والرابع إلى النهاية.
- ستة أوجه للنرد و21 نقطة، مشاركة وعد الحركة عند الطلب المكرر، واستقرار النتيجة النهائية.
- منع النقاط بعد مهلة التصويب، ومنع مؤقت الذاكرة القديم من تغيير جولة جديدة، ومنع الادخار/إعادة اللعبة أثناء رمية النرد.
- منافسان في مواجهة سيرفر حقيقية الكود عبر Worker المحاكى، وأربع طلبات انضمام متزامنة تنتج مواجهتين منفصلتين.
- منع تخمين سر اللاعب وتزوير النقاط والإجابات المكررة أو القديمة أو عند المهلة الدقيقة، وحجب الإجابة حتى الكشف.
- مرور عشر جولات حتى النهاية عبر إنذارات السيرفر، وإضافة المكافأة الموثقة مرة واحدة للحساب الصحيح.
- تعثر تجهيز مواجهة ثم استعادتها بالتذكرة نفسها دون فقد اللاعبين؛ تعثر المكافأة ثم إعادة محاولتها دون تكرارها.
- رفض رمية تحمل إصدار غرفة قديم؛ تثبيت هوية الجولة عند إعادة الاتصال.
- رفض تجهيز عنصر غير مملوك، ورفض الشراء برصيد ناقص، وتجاهل السعر المزوَّر، وعدم خصم العنصر مرتين عند تكرار النقر.
- حفظ نتائج التدريب المنقطعة ثم محاكاة إعادة تحميل ومزامنة نتيجتين مرة واحدة؛ عدم مزامنة نتائج حساب إلى حساب آخر؛ عدم اعتماد استجابة الحساب القديم بعد تغييره.
- فحوص الحسابات والصداقة والدعوات والحظر والخصوصية وعودة الاتصال الموجودة في المشروع.

## ما لم يُختبر ميدانيًا

لم تُجرَ تجربة رسم أو لمس أو صوت أو Service Worker في متصفح حقيقي أو هاتف فعلي. DOM المستخدم للاختبار محاكاة تستهدف سير التفاعل والحالة، ولا يمثل قياسًا للتصميم المرئي أو أداء الأجهزة. لم تُجرَ محاكاة حمل أو اختبارات متانة شاملة لكافة الأعطال الممكنة.

لم يُشغَّل Wrangler dry-run السحابي أو يُنشر Worker، ولم تُغيَّر قواعد Firestore في الحساب الخارجي. حماية Firestore المرفقة لا تصبح فعالة على الخدمة القديمة حتى نشرها. ألعاب اللوحات والمواجهة السريعة للحساب مرتبطة بمكافآت السيرفر؛ غرف اختبار العباقرة الخاصة لا تمنح ترتيبًا موثقًا في هذا الإصدار.

## قبول النسخة المنشورة

قبل اعتمادها للإنتاج: نفّذ تعليمات DEPLOY-AR.txt، تحقق من /api/health بالإصدار 6.0.0، ثم جرّب جهازين للمواجهة السريعة والثعبان، وأربع جلسات للجاكارو، وشراء تخصيص وظهوره على حساب الجهاز الثاني، وانقطاع الاتصال والمزامنة وإعادة الجولة. نفّذ تجربة Android وiOS والتثبيت ثم اللعب المحلي دون شبكة.

النتيجة المدعومة بالأدلة: لا توجد إخفاقات في الفحوص المنفذة لهذه النسخة. لا تعني هذه النتيجة ضمان غياب جميع الأخطاء على كل المتصفحات أو في إعداد إنتاج لم يُختبر.
