# Tahdia — تطوير مشغّل البلوت وتجهيز الصوت البشري

الإصدار محفوظ: **33.0.0**. تاريخ التحديث: **29 أكتوبر 2026**.

## الحالة الفعلية

تم تطوير مشغّل النداءات وربط الواجهة بمسار التسجيلات البشرية. **استبدال الصوت بتسجيل بشري لم يكتمل**؛ لا توجد تسجيلات بشرية مستلمة أو معتمدة ضمن هذه الحزمة. الصوت الاصطناعي المرفوض لا يُشغّل تلقائيًا، وتستمر النداءات المكتوبة أثناء اللعب. تظهر الواجهة حالة الانتظار بوضوح، وتتعطل أزرار التجربة والإعادة إلى أن تكتمل الحزمة البشرية المعتمدة.

الحزمة تحديث جزئي تراكمي فوق المصدر المتوافق 33.0.0، وليست المشروع كاملًا. قد تتضمن أصولًا صوتية قديمة للمحافظة على توافق المصدر وسجله؛ المشغّل الجديد لا يرجع إليها ولا يستخدم صوت الجهاز بدل التسجيل المطلوب.

## ما تغيّر

- النداء يُشغّل كاملًا بسرعته وطبقته الأصليتين. النداءات المهمة تحافظ على ترتيب وصولها ولا تقطع الكلمة الجارية.
- إلغاء الطلبات المنتظرة عند الخروج أو كتم الصوت، وإهمال الاستجابات المتأخرة والنداءات القديمة.
- تحميل مسبق محدود وذاكرة مقاطع محدودة، مع إظهار فشل التحميل وإمكانية إعادة المحاولة.
- زر «جرّب النداء»، وزر «إعادة آخر نداء»، وعرض آخر عبارة وحالة الصوت.
- منع استمرار دفعات الأحداث والكلام المؤجل من طاولة سابقة عند الخروج وفتح طاولة أخرى.
- إبطال كاش ملفات التشغيل عند تبديل حزمة الصوت، مع الاحتفاظ برقم الإصدار.
- أداة استيراد للتسجيلات الـ56: فحص الأسماء والملفات والصمت والمدة، ثم تحويل الملفات كاملة إلى MP3 دون قص الكلمات أو تغيير السرعة. لا تعتمد الحزمة الناقصة، ولا تفعّل حزمة دون تأكيد المراجعة السمعية.
- تصحيح شرح اللعب المفتوح ليوافق سلوكه الحالي: اختيار أي ورقة بضغطة واحدة دون تظليل للقطع.

المصدر المعتمد هو SAME-UPDATE للإصدار 33.0.0 بعد تطبيق التحديث الجزئي المحفوظ والتحقق من بصماته. الحزمة القديمة ذات الاسم v34.0.0-FULL سبقت هذا الدمج حسب توثيق المشروع، ولم تُستخدم أساسًا للتطوير.

## التحقق

- **959 اختبار JavaScript ناجحًا، دون فشل أو تخطي**، ضمن `npm run verify`.
- **4 اختبارات Python ناجحة** لمسار التسجيل والتحويل، منها تحويل 56 ملف WAV تجريبيًا والتحقق من بقاء الملفات الأصلية والمدة. ملفات الاختبار نغمات مؤقتة وليست تسجيلات بشرية، ولا تُدرج في الصوت الفعلي.
- **6 اختبارات ناجحة لأداة تطبيق التحديث**: الفحص دون كتابة، وإعادة التطبيق، ورفض المصدر المتغير والحمولة الفاسدة والمسارات الخارجية، والتراجع عند فشل الكتابة.
- فحص **701 مرجع محلي** للملفات، وفحص إعدادات ومحرك Worker، والتحقق من بناء CSS وملف العمل دون اتصال.
- نجاح فحوص Workerd وSQLite المحلية وتجميع Cloudflare التجريبي. لم يُنشر التحديث على الموقع.
- فُحص منطق الواجهة داخل محاكاة DOM. **اختبار المتصفح الفعلي لم يكتمل**: المتصفح غير مثبت وتنزيله لم يكتمل. لم يُجر اختبار على iPhone أو Android فعلي، ولا مراجعة سمعية لتسجيل بشري.

توجد السجلات في `verification/voice-development/`. يبقى اختبار النطق وبدايات الكلمات ونهاياتها داخل مباراة فعلية شرطًا لاعتماد التسجيلات، ولا تثبته اختبارات الكود.

## تطبيق التحديث

إذا كان مسار الرفع الحالي يدعم `busraj-sparse-patch-v1`، ارفع ملف ZIP كما هو إلى المسار الذي يشغّل تحديث المشروع. لا تفك `game-patch` فوق جذر المستودع يدويًا. عند رفض بصمة ملف، توقف واستخدم نسخة المصدر الحالية لتجهيز تحديث مطابق؛ لا تتجاوز الفحص.

للتطبيق المحلي، فك ZIP في مجلد مستقل، ثم افحص المجلد الصحيح للمشروع:

```bash
python3 APPLY_UPDATE.py --project /path/to/tahadi-alabaqera-online-pro-fixed
```

لتطبيق الملفات بعد نجاح الفحص:

```bash
python3 APPLY_UPDATE.py --project /path/to/tahadi-alabaqera-online-pro-fixed --apply
```

الأداة تفحص بصمات جميع الملفات قبل استبدالها، وترفض الملفات المتغيرة، وتعيد الملفات التي استبدلتها إذا فشل التطبيق. لا تغيّر ملف إعداد الاستضافة. بعد التطبيق شغّل فحوص المشروع، ثم انشر السيرفر و`public` معًا بالطريقة المعتادة. أغلق التطبيق وأعد فتحه لتحديث الملفات المخزنة.

## إكمال الاستبدال البشري

القائمة المعتمدة محفوظة في `public/assets/js/baloot-voice-pack.js` تحت `VOICE_LINES`، وهي 56 عبارة كاملة تطابق ملف التسجيل السابق. المطلوب ملف WAV مستقل لكل اسم، مثل `pass.wav` و`sun.wav` و`review_projects.wav`. تُراجع تجربة أولى بالنبرة السعودية أو الخليجية الطبيعية، ثم تُعتمد القائمة كاملة سمعيًا مع تحديد استخدام التسجيلات مع صاحب الصوت.

لفحص الملفات دون تغيير المشروع:

```bash
python3 scripts/import-baloot-voices.py --recordings /path/to/wav-files --speaker 'اسم المعلّق' --dry-run
```

بعد مراجعة التسجيلات كاملة، للاستيراد والتفعيل:

```bash
python3 scripts/import-baloot-voices.py --recordings /path/to/wav-files --speaker 'اسم المعلّق' --reviewed
node scripts/build-offline.mjs
node scripts/refresh-checksums.mjs
npm run verify
npm run test:voice
```

تحتاج أداة التحويل Python 3 وFFmpeg وFFprobe. فحوص الصمت والمدة لا تحكم على النطق أو طبيعية الأداء. التسجيلات الأصلية تبقى كما هي. تُفعّل حزمة كاملة مع بصمات لكل ملف، ويُولّد كاش جديد كي لا تبقى نسخة الانتظار القديمة.
