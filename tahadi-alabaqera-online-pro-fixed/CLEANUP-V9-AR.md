# نسخة V9 المخففة

حُذف ٥٤ ملفًا قديمًا غير مستخدم في التشغيل الحالي: صورة اللوحة السابقة وأصواتها المكررة وملفات تنسيق متروكة وصورة إضافية وإعدادات Firebase غير المستدعاة، مع سجلات وخطط الإصدارات القديمة. تم التحقق من مراجع الصفحات والمحركات وبيانات الأسئلة قبل الحذف. القائمة الدقيقة في CLEANUP-V9.json.

تحولت الرسومات الأربع الحالية إلى WebP بضغط دون فقد: الثعبان، إطار اللوحة، الأحجار والسلالم، وطاولة الجاكارو. بقيت الأبعاد والشفافية والبكسلات الظاهرة مطابقة للأصل. تم تحديث جميع مراجع هذه الرسومات وكاش الملفات المحلية. الأصوات الجديدة ووسائط الأسئلة المستخدمة بقيت كما هي.

القواعد وشرط الدخول بـ٦ والوضع المطوّر ونرد المكافآت والسيرفر والمتجر والألعاب لم تتغير. بقيت الملفات التي تستخدمها اختبارات المشروع.

الفحوص: ٢٠٠ اختبار ناجح، لا فشل، و٦ اختبارات Shell متخطاة كما في V9. فُحص ٤٩٧ مرجعًا محليًا، و١٠٧ ملفات JavaScript، و٩ سكربتات مضمّنة، و٢٣٤ مسار كاش. فحص Worker المحلي وإعداداته نجح. تشغيل الخادم المحلي أثبت إتاحة الصفحات ووحدات اللعبة والرسومات الأربع بصيغة WebP والأصوات الجديدة عبر HTTP 200 وMIME الصحيح.

هذا تحديث لتقليل حجم الحزمة؛ الفحص البصري الإضافي في المتصفح لم يتكرر بسبب حد الاستخدام السابق. تقرير V9 يذكر حدود فحص اللعب البصري.

التشغيل: فك الحزمة، افتح مجلد snake_pro_v9، ثم npm run start:local. استخدم هذه الحزمة كاملة عند الاستبدال حتى تتطابق أسماء ملفات WebP مع مراجعها.
