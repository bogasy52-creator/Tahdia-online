بوسراج 3.0 — قائمة فحص النشر
============================

قبل النشر:
1) npm install --include=dev
2) npm run verify
3) npm run check:cloudflare
4) sha256sum -c SHA256SUMS.txt
5) npm run deploy

Cloudflare / Durable Objects:
- لا تحذف أو تعيد ترتيب migrations القديمة.
- يجب بقاء BoardGameRoom -> BoardRoom كما هو.
- يجب وجود SOCIAL_USERS -> SocialUser.
- يجب أن تأتي v4-social-users بعد v3-board-room-rename.

اختبار الحسابات والأصدقاء بعد النشر:
- أنشئ حسابين مختلفين من متصفحين/جهازين.
- أرسل طلب صداقة من الحساب الأول واقبله من الثاني.
- تأكد أن كلا الحسابين يظهران في قائمة الأصدقاء.
- افتح اتصال Social وتأكد من ظهور Online/Offline في الطرف الآخر.
- غيّر الخصوصية إلى "الأصدقاء فقط" واختبر الدعوة.
- احظر مستخدمًا وتأكد من إزالة الصداقة ومنع الدعوات.

اختبار دعوة اللعب:
- أنشئ غرفة جاكارو وأرسل دعوة لصديق؛ يجب أن يفتح الرابط نفس كود الغرفة.
- كرر مع سباق الـ100 والزهرة وتحدي العباقرة.
- جرّب كود غرفة يخص لعبة أخرى؛ يجب رفض الدعوة من السيرفر.
- ابدأ المباراة ثم حاول إرسال دعوة جديدة؛ يجب رفضها.

اختبار الألعاب الحالي:
- سباق الـ100: اللوحة بعرض الشاشة والحجر لا يُقص أثناء الحركة.
- الزهرة: حركة وأكل ورجوع للبيت واضح.
- جاكارو: حركة عادية + J تبديل + 7 كاملة ومقسمة، والخصوم لا يرون الأوراق.
- Landscape: التحكم ينتقل بجانب اللوحة على الهواتف القصيرة.
- Reconnect: افصل لاعبًا وأعد اتصاله وتأكد من استعادة المقعد.

PWA:
- App shell cache = busraj-games-v14
- Quiz media cache = busraj-quiz-media-v3

مهم:
- انشر المشروع كاملًا وليس public فقط.
- نظام ZIP يستخدم merge-worker-config.mjs لإضافة migrations الجديدة Append-only فقط.
- أي فشل في اختبارات أو merge إعداد Cloudflare يعني عدم النشر.
