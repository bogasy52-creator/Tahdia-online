بوسراج للألعاب 2.2 — تقرير الفحص النهائي
التاريخ: 2026-08-31

النتائج المحلية المؤكدة:
- 32/32 اختبار Node ناجح (0 فشل).
- فحص المراجع المحلية نجح: 59 مرجعًا محليًا بدون ملفات مفقودة.
- JavaScript الأساسي + سكربتات HTML المضمنة اجتازت node --check.
- manifest.webmanifest صالح JSON.
- لا توجد ملفات صفرية الحجم ضمن ملفات المشروع المعبأة.
- لا توجد ملفات .env أو مفاتيح/credentials معروفة ضمن الحزمة.
- SHA256SUMS.txt أعيد توليده للإصدار 2.2 ويجب أن يجتاز sha256sum -c SHA256SUMS.txt.

إصلاحات 2.2 — الأونلاين والحماية:
- منع guest من الحصول على صلاحية host عند دخوله قبل منشئ الغرفة.
- نقل hostKey وreconnect token خارج WebSocket URL إلى subprotocols.
- فرض بروتوكول busraj-v1 على اتصالات WebSocket.
- رفض API/WebSocket من Origin خارجي وإزالة CORS wildcard.
- Rate limiting لإنشاء الغرف، status، وWebSocket؛ Durable Object مع fallback محلي.
- تنظيف عدادات Rate Limit المنتهية بدون مسح عدادات ما زالت فعالة.
- مهلة reconnect في اللوبي 45 ثانية قبل تحرير المقعد.
- نقل الاستضافة تلقائيًا بعد انتهاء مهلة host المنقطع عند وجود لاعب متصل.
- تنظيف الغرف عند انتهاء expiresAt بدل بقائها معلقة.
- ألعاب اللوح: مهلة دور 60 ثانية ومعالجة تلقائية عند عدم استجابة اللاعب + عداد مرئي مصحح مقابل وقت السيرفر.
- الزهرة: مهلة 25 ثانية لاختيار الحركة بعد الرمية.
- ألعاب اللوح: leave صريح من اللوبي وتحرير المقعد/نقل الاستضافة عند الحاجة.
- rematch يعيد اللاعبين إلى lobby ويلغي ready حتى يجهزوا من جديد.
- جاكارو: إصلاح ورقة 7 لتدعم تحريك حجر واحد 7 خطوات أو تقسيمها.
- جاكارو أونلاين: أوراق الخصوم تظل masked من snapshots.

إصلاحات الواجهة/PWA:
- Escape لأسماء اللاعبين قبل استخدامها في innerHTML في صفحات الألعاب المحلية.
- Escape كذلك لعرض أسماء/أفاتار اللاعبين في واجهة الغرف الأونلاين.
- Service Worker محدث إلى cache v7.
- تخزين best-effort لصور الأسئلة الخارجية في Cache Storage لتحسين العمل عند ضعف الشبكة.

ملاحظة Wrangler:
- بيئة الفحص الحالية لا تحتوي node_modules/wrangler ولا تسمح بجلب الحزمة من npm بشكل موثوق، لذلك لم يتم اعتماد wrangler deploy --dry-run كاختبار ناجح هنا.
- package.json يثبت wrangler على 4.127.1.
- قبل النشر على جهاز متصل: npm install ثم npm run verify ثم npm run deploy.
- /api/health بعد النشر يجب أن يعرض version:"2.2.0" مع quizOnline:true وboardOnline:true.

ملاحظة اختبار Chromium:
- محاولة Chromium headless داخل بيئة الفحص لم تكتمل بسبب قيود/مشاكل بيئة المتصفح (DBus/zygote/timeout)، لذلك لم يتم احتسابها كاختبار ناجح.
- بدلًا منها تم الاعتماد على 32 اختبارًا + فحص المراجع + فحص syntax + اختبارات regression للحماية والأونلاين.
