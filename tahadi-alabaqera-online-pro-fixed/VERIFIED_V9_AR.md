# فحص إصدار V9 · 9.0.0

- npm run verify:release: نجح. ٢٠٦ اختبارات إجمالًا؛ ٢٠٠ ناجحة، لا فشل، و٦ اختبارات Shell متخطاة من الإصدارات السابقة.
- اختبارات شرط الدخول بـ٦، والخانات الثلاث فقط، وحماية ابتلاع واحد، ودورين إضافيين بالعدد الصحيح، والنرد المزدوج، وحركة المكافأة عبر الثعابين، وتجميد دور واحد.
- محاكاة ٨٠ مباراة كاملة بالقواعد المطوّرة والقدرات المكتسبة؛ انتهت جميع المباريات بوصول الفائز إلى ١٠٠، دون خروج الأحجار عن اللوحة أو تجاوز حدود رصيد القدرات.
- اختبارات مسارات الثعابين وثبات الرأس والذيل، وعدم تمدد الرأس مع طول المسار، وهدوء الحركة بين الإطارات. اختبارات الرسم والنمو والإيقاف والعودة إلى الحجم الطبيعي، والمؤقت المستقل عن إطارات الرسم.
- تشغيل رسم Canvas محليًا بملفات الصور الفعلية داخل محرك Canvas 2D: ظهرت ٨ ثعابين و٨ سلالم، وفُحصت الرؤوس الأكبر والقشور والألوان وطبقة أرقام الخانات. هذا فحص لمحرك الرسم، وليس لقطة متصفح نهائية.
- فحص متصفح فعلي اكتمل قبل الحجب: الوقوف على ١٢ يفتح نرد الرموز؛ وجه «دوران إضافيان» يطبق المكافأة؛ رمية ٦ تدخل إلى الخانة ١ وتبقي الدور؛ النرد المستقر يظهر وجه ٦ كاملًا، وبقية الأوجه مخفية.
- فحص WAV: المجموعة الجديدة من ٢٠ ملفًا ستيريو PCM، مع مستوى ذروة يترك هامشًا لأصوات متزامنة. مدير الصوت يوجّه مؤثرات اللعبة إلى هذه الملفات، ويحترم كتم الصوت وإعدادات المؤثرات والمؤقت. لا يتضمن التقرير ادعاء مراجعة سمعية لكل ملف.
- فحص الملفات: ٤٩٧ مرجعًا محليًا، و١٠٧ ملفات JavaScript، و٩ سكربتات مضمّنة، و٢ مراجع صور CSS، و٢٣٤ مسارًا للتخزين دون اتصال. فحص Worker المحلي وإعداداته نجح.

## حدود الفحص

رفضت المراجعة الآلية فحص المتصفح الإضافي بسبب بلوغ حد الاستخدام. لذلك لم يكتمل فحص بصري داخل المتصفح بعد آخر تكبير للثعابين ونقاط النرد. لا توجد لقطة متصفح نهائية لهذا التعديل، ولا ادعاء اختبار سيرفر منشور أو جهاز Android فعلي.
