# تحقق الإصلاح 11.0.2

نجح npm run verify:release: ٢٧١ اختبارًا إجمالًا، ٢٦٥ ناجحة، صفر فشل و٦ اختبارات Shell قديمة متخطاة. السجل في docs/verification/v11_2/release.log.

الصورة تؤكد تجاوز حصة طلبات Cloudflare اليومية. فحص الكود وجد حلقة مؤقتات عندما ينقطع المضيف ولا يوجد لاعب متصل يستلم الغرفة. أُعيد إنتاج الحلقة في V11.1 بمحرك workerd الفعلي وتخزين SQLite: المؤقت التالي بعد نحو ٥٠ مللي ثانية. بعد الإصلاح ينتظر المؤقت انتهاء الغرفة بعد ٢٤ ساعة مع الحفاظ على حق رجوع المضيف. هذا خلل مثبت في الكود، لكن تحديد حصته من استهلاك حسابك يحتاج إحصاءات Cloudflare.

نجحت ٨ فحوص عبر workerd وSQLite وWebSocket: مؤقت الغرفة المهجورة، توقف تنظيف الطابور الفارغ، الكلاسيك بأربعة لاعبين والمطوّر بلاعبين من إنشاء الغرفة والانضمام والجاهزية والبدء حتى الرمية المتزامنة، إنشاء الجاكارو والزهرة وقراءة حالتهما، دخول BoSraG و٦ صلاحيات إدارة و٤٢ مقتنى، وتمرير خطأ حصة محقون مع إيقاف تكرار تهيئة الغرف. محرك الاختبار فعلي؛ نفاد الحصة في الفحص الأخير محقون عمدًا، ولا يدعي الوصول إلى حد حساب Cloudflare الحقيقي. سجل قبل الإصلاح وبعده في docs/verification/v11_2.

نجح npm ci --include=dev وnpm run check:cloudflare بواسطة Wrangler 4.127.1. بقي wrangler.jsonc وأسماء المحركات وسجل الترحيلات مطابقًا للنسخة الأصلية V6.

الاختبارات الجديدة تغطي مهلة رجوع المضيف وانتقال الإدارة، تنظيف تذاكر الطابور عبر عدة صفحات تخزين، رسالة حد الطلبات وإعادة الضبط عند منتصف الليل UTC، توقف الفحص الإضافي للغرف وتكرار استعلامات المواجهة عند هذا الخطأ. فحوص المتجر والمدير والمكافآت وقوانين اللعب السابقة ناجحة.

لم يُنفَّذ نشر إلى حسابك أو تعديل بيانات حية، ولم يُختبر متصفح أو جهاز حقيقي في هذه الجلسة. واجهات الخطأ اختُبرت في DOM محلي.

الحصة المجانية لا يعيدها تحديث الملفات: تتجدد عند 00:00 UTC، أي ٣ صباحًا في السعودية. انشر المشروع كاملًا لتطبيق إصلاح المؤقتات على السيرفر. الحد يخص حساب Cloudflare، وأي استخدام آخر في الحساب قد يستهلكه أيضًا. المرجع: https://developers.cloudflare.com/durable-objects/platform/pricing/

فُحص محتوى ZIP وCRC والبصمات بعد إعداد الحزمة. تتضمن الحزمة الألعاب والرسومات والأصوات والمتجر والإدارة السابقة؛ لا تتضمن node_modules أو بيانات تسجيل دخول.
