# تحقق V10 — 10.0.0

نجح npm run verify:release: ٢١٩ اختبارًا إجمالًا؛ ٢١٣ ناجحة، صفر فشل، و٦ اختبارات Shell قديمة متخطاة. فُحصت ٤٩٩ إحالة محلية، و١١٣ وحدة JavaScript، و٩ سكربتات مضمّنة، و٢٣٥ مسار كاش. نجح فحص Worker وإعداداته محليًا. السجل الكامل في docs/verification/v10/release.log والنتائج في result.json.

اختبارات الأونلاين تشغّل مسار إنشاء الغرف الفعلي في Worker وطرق Durable Object عبر محاكاة تخزين واتصال محلية. تشمل حفظ كلاسيك/مطوّرة، النرد والمكافأة من السيرفر، استهلاك قدرة النردين مرة واحدة، رفض إعادة الرمية والقدرات غير المكتسبة، الحماية، مكافآت انتهاء الوقت، استعادة الغرفة من التخزين وإعادة المباراة بالأسلوب نفسه. محاكاة DOM تثبت ظهور القدرات والخانات الثلاث والنردين واكتمال عرض المكافأة لدى المتابع. تُكتشف الخدمة القديمة بدل تبديل المطوّر إلى كلاسيك بصمت.

فحص المسافات عند عروض ٣١٠ و٣٩٠ و٧٠٩ بكسل يثبت بقاء جميع أجسام الثعابين خارج مستطيلات رؤوس الثعابين الأخرى، مع هامش. نُقل الذهبي من المسار المتقاطع القديم إلى ٦٨←٥٠، والمحرك والرسم يستخدمان الخريطة نفسها. عند استكمال جولة سابقة يرسم العميل خريطة تلك الجولة المحفوظة.

الفحص البصري استخدم Canvas 2D محليًا لتشغيل كود الرسم الفعلي، مع ٨ ثعابين و٨ سلالم والأصول الحالية. الأرقام بلا خلفيات، والرؤوس بطلاء نيون يحافظ على ألوان الفم والأسنان، والأجسام بقشور أصلية وحواف ضوء متدرجة. تحققت حالات النمو والاهتزاز والتوقف والعودة بالحالات والأزمنة في اختبارات الرسم.

نجح فحص HTTP للصفحات ووحدات الرسم الجديدة ورسومات WebP الأربع وصوت الابتلاع. بقيت حزمة الرسومات بضغط دون فقد، والأصوات الجديدة وبقية الألعاب موجودة.

حدود التحقق: لم يُنفذ لعب كامل في المتصفح لهذه النسخة بسبب حد استخدام المتصفح الذي منعه التحقق التلقائي من الموافقة في الجلسة السابقة. Canvas ليس لقطة متصفح. لم يُنفذ نشر Cloudflare أو اختبار أونلاين بين جهازين حقيقيين أو استماع لكل ملف صوتي. هذه الاختبارات المحلية لا تثبت أداء الخدمة المنشورة؛ نشر الحزمة كاملة مطلوب للأونلاين المطوّر.
