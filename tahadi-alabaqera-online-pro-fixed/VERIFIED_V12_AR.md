# التحقق من Snake PRO V12 — 12.0.0

نجح npm run verify:release: ٢٩٦ اختبارًا إجمالًا، ٢٩٠ ناجحة، صفر فشل و٦ اختبارات Shell قديمة متخطاة كما في V11.2. نجح فحص ٥٦٦ مرجعًا محليًا، و١٣٤ ملف JavaScript، و٩ سكربتات مضمنة، و٢٤٧ مسارًا في كاش التطبيق. السجل: docs/verification/v12/release.log.

نجح npm run check:cloudflare بواسطة Wrangler 4.127.1: ٢٤٥ ملف واجهة، وحزمة Worker قابلة للبناء. لم يتغير wrangler.jsonc أو أسماء المحركات أو تاريخ الترحيلات عن V11.2. لم يُنفذ نشر أو تعديل بيانات حية.

نجحت الفحوص الأصلية الثمانية عبر workerd وSQLite وWebSocket: الغرفة المهجورة والطابور الفارغ، كلاسيك الثعبان ومطوّره حتى الرمية المتزامنة، إنشاء الزهرة والجاكارو، دخول BoSraG وصلاحياته ومقتنياته، وخطأ حصة طلبات محقون مع إيقاف التكرار. السجل: docs/verification/v12/native.log.

خضع الجديد لمتصفح Chromium فعلي مع Playwright وسيرفر workerd محلي، وليس DOM محاكى فقط. شملت الفحوص: ستة أنواع ثعابين بمعاينات مرسومة مختلفة؛ عدم الشراء أثناء المعاينة؛ هدية يومية وشراء فعلي وتجهيز؛ لاعبان بشاشتين وتوقف واستئناف؛ عرض ٣٩٠×٨٤٤ والتحكم باللمس؛ غرفة بلاعبين من سياقَي متصفح مستقلين؛ مقارنة حالة اللعب نفسها عند رقم محاكاة مشترك؛ إعادة تحميل الصفحة والرجوع لنفس اللاعب؛ الرجوع لغرفة منتهية وإعادة الجولة. لم تظهر أخطاء JavaScript في الصفحات. فُحصت صور العرض داخليًا على ١٣٦٦×٩٠٠ و١١٠٠×٨٠٠ و٣٩٠×٨٤٤.

شملت المراجعة المستقلة أربع حالات مهمة، وأُعيد إنتاج كل واحدة باختبار فاشل قبل إصلاحها: تحرير التسريع عند إخفاء التبويب، الرجوع للنتائج بعد انتهاء الجولة، إظهار جسم الثعبان الطويل عندما يخرج رأسه من الكاميرا، وعدم إلغاء محاولات إعادة الاتصال عند أول فشل. الاختبارات الجديدة ناجحة.

الفردي يقارن نتيجة اللاعب بالبـوتات؛ لا يمنح اللاعب الفوز تلقائيًا. البوتات واضحة بوسم BOT، ولا تدخل الغرف الجماعية. الصعوبات تستخدم إعدادات حركة واستباق محددة. مقاعد اللاعبين المنقطعين محفوظة للرجوع حتى انتهاء الغرفة أو المغادرة الصريحة.

حدود التحقق: لم تُختبر أجهزة Android أو iOS فعلية ولا Safari ولا حساب Cloudflare المنشور الخاص بك. الاختبار المحلي يثبت اتصال الجماعي وعمل السيرفر؛ نشر الملفات الكاملة مطلوب لتشغيله على موقعك. لم يُختبر حمل عشرات الغرف المتزامنة. إصلاح الحصة السابق محفوظ، لكنه لا يزيل الحد المجاني للحساب.

أُعيد فحص ZIP وCRC ومطابقة كل ملف مصدر بعد الحزم. لا تتضمن الحزمة node_modules أو بيانات حسابات الاختبار المحلية أو صور الفحص.
