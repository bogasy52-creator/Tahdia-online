# تحدي العباقرة — الإصدار 26.0.0

هذه حزمة المشروع كاملة: الواجهة، الألعاب، الرسومات، خدمة الغرف والحسابات، والاختبارات. يلزم تحديث الواجهة والسيرفر معًا حتى تصل إصلاحات الأونلاين إلى اللاعبين.

## ما تغيّر

- واجهة رئيسية جديدة بألوان كحلية وذهبية، خط عربي محلي، رسمة جديدة، بحث عربي وتصنيفات ودخول غرف واضح. شريط تنقل واحد للعب، مع بقاء الصوت والإعدادات والقواعد وأزرار المغادرة متاحة.
- تحسين العرض والتباعد والنصوص واللمس في صفحات الألعاب، مع الحفاظ على محركات وقواعد اللعب الحالية.
- إزالة التصويب من المشغّل والقوائم والدعوات. رابطها القديم يعيد اللاعب إلى مكتبة الألعاب.
- تنقية المتجر: أرشفة 12 إضافة متشابهة وإخراج عناصر البداية المجانية من واجهة البيع. المقتنيات القديمة تبقى لأصحابها داخل «خزانتي» ويمكن تجهيزها.
- ثلاثة أنواع نرد جديدة: البورسلان والكريستال والأوبسيديان، بحواف ونقاط وتفاصيل مختلفة. إصلاح تنسيق كان يفرض اللون الافتراضي على الأشكال المختارة. الرمية تستقر على وجه فعلي وتحتفظ بمنطق النتائج العادلة.
- ثعبان «سيّد الحلبة» للمدير: جسم داكن وذهبي وتاج وأثر نجمي محدود. يُمنح من السيرفر لحساب المدير الموثّق bosrag، ولا يغيّر القوة أو سرعة اللعب.
- إصلاح انتظار الاتصال، ومهل الطلبات، وفحص الاتصال الصامت واستعادته، وتنظيف الاتصالات السابقة. حالة «متصل» تظهر بعد قبول الغرفة للاعب.
- منع تداخل الدخول التلقائي من الدعوة مع الضغط السريع على زر الدخول، وإبطال طلبات الانضمام القديمة بعد إغلاق العميل.
- منع التبويب القديم من استعادة المقعد تلقائيًا بعد نقل الجلسة إلى تبويب آخر.
- دعوات محفوظة عند غياب اللاعب، مع منع التكرار السريع وانتهاء صلاحية البطاقة وتنظيفها عند تبديل الحساب. لا يُقبل رابط دعوة خارجي أو دعوة إلى مباراة بدأت.
- توحيد رقم الإصدار ومفاتيح التخزين المؤقت لمنع اختلاط الواجهة الجديدة بملفات قديمة. الحفاظ على ربط قاعدة البيانات وترحيلات الغرف الحالية.

## التشغيل

من مجلد `tahadi-alabaqera-online-pro-fixed`:

```bash
npm ci
npm run dev
```

للتجربة المحلية دون خدمة الحسابات والغرف:

```bash
npm run start:local
```

## التحقق وإعداد النشر

```bash
npm run verify:release
npm run check:cloudflare
npm run test:online:v26
```

فحص المتصفح قابل لإعادة التشغيل:

```bash
npx playwright install chromium
npm run test:browser:v26
```

لرفع التحديث إلى حساب Cloudflare المرتبط بالمشروع:

```bash
npm run deploy
```

بعد النشر افتح `/api/health` وتأكد أن قيمة `release` هي `26.0.0`، وأن الخدمات المطلوبة تعمل. لا تغيّر أسماء الـ bindings أو تاريخ الترحيلات في `wrangler.jsonc` عند دمج الحزمة مع إعدادات حسابك.

## حدود التحقق

الاختبار تم على نسخة محلية من Worker مع SQLite واتصالات WebSocket حقيقية، وفي متصفح Chromium على الكمبيوتر ومقاس جوال. لم يُنشر هذا العمل على موقعك الفعلي، ولم تُختبر شبكة الاستضافة وحصتها اليومية أو أجهزة iOS الحقيقية. تفاصيل النتائج في `VERIFICATION_V26_AR.md`.
