# Snake PRO V12 design

The user has authorized the full upgrade and execution. Work continues from the V11.2 ZIP as a new release, preserving the original as the prior release.

## Outcomes
- Replace repetitive store thumbnails with distinct, animated representations for each cosmetic type. Add a large item inspection modal with an actual rendered preview, ownership and current price, and an explicit purchase/equip action.
- Organize the store into a clean dark editorial layout: one feature area, compact balance, horizontally scrolling category tabs, concise cards, collections, inventory and existing real missions. Preserve server price checks and accounting.
- Add Serpent Arena: smooth moving snakes, food growth, defeated-snake drops, body collision, boost that costs mass, bounded arena, bots, keyboard/mouse/touch controls, local solo and two-player modes.
- Add real online rooms for 2–8 players, server simulation over WebSocket, ready/start/rematch controls and disconnect recovery. Bots must never be presented as real online opponents.
- Use the existing GameRoom Durable Object namespace with isolated name prefixes. Keep wrangler.jsonc bindings and historical migrations unchanged.
- Preserve all board game rules, manager entitlement checks, earlier quota fixes, social accounts and existing assets. Improve board cosmetics and add access to the new arena from the home page and store.

## Architecture
Shared deterministic Serpent engine is imported by both browser and server. Renderer uses canvas; menus and HUD use Arabic RTL DOM. Only the server accepts movement inputs and calculates online scores, growth, deaths and the match outcome. Simulate in bounded fixed steps while connected; use an expiry alarm, never tick alarms. Stop timers with no connected players. Save a checkpoint every five seconds and lifecycle changes.

## Acceptance
Engine tests cover eating, death drops, collisions, boost cost, bounded steps, malformed input and deterministic bots. Worker tests cover room creation, duplicate initialization, invalid player counts, readiness, server authority, reconnect and timer shutdown. Real browser checks, if available, cover mobile controls, store modal purchases and two-client online synchronization. Existing release tests and static references must continue to pass.

## Visual direction
Dark navy, warm ivory text, jade and copper accents; illustrated individual silhouettes, restrained effects, clear prices and large mobile touch targets. Playfield takes the main viewport, with a narrow HUD and thumb controls at the edges. Nonessential animations respect reduced motion.
