# Snake PRO V12 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the authorized V12 store and real Serpent Arena upgrade.
**Architecture:** Shared canvas simulation, a server room delegate inside the existing GameRoom binding, and standalone DOM store previews.
**Tech Stack:** JavaScript ES modules, HTML/CSS, Cloudflare Durable Objects, Node test runner.
**Spec:** docs/superpowers/specs/2026-10-12-v12-design.md

## Global Constraints
- Keep existing bindings, migrations, board rules, manager identity and quota behavior.
- Online actions send steering inputs only; state and score come from the server.
- Existing tests stay green; no new package dependency is required by the delivered game.

## Review Focus
- Hidden tabs and lost connections must release boost and stop unattended timers.
- Guest reconnect tokens must not grant host access.
- A store preview must not equip or debit coins until the user chooses an action.
- Pointer scaling must stay correct after resize and on mobile RTL layouts.
- Finishing and rematching must prevent reward duplication.
